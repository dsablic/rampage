Adaptations: Accept selected windows/clangwindows compiler context with int=4, long=4 and pointer=4/8.
The WinAPI subset is bounded to x86/x64. On x86, emit __stdcall for recv/CreateFileW; memcpy is C cdecl.
On x64, use the selected Windows compiler's unified model, not an x86 __stdcall model.
recv returns int4, takes uint{pointer} SOCKET, char *buffer, int4 length and int4 flags. This corrects
the generic runtime catalog's POSIX recv shape, including on Win64 (LLP64, not LP64).
CreateFileW returns void * HANDLE, takes uint2 * filename, uint4 access/share/disposition/flags,
void * security attributes and void * template handle. Omit const/attributes/macros/includes;
security attributes remain opaque: no structure layout is imported or inferred.
Only exact names and exact _recv@16 / _CreateFileW@28 x86 stdcall decoration are accepted.
Header provenance and an import spelling do not prove an implementation, runtime OS or producer.
