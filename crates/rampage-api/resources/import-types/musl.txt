Adaptations: Reuse rampage's native runtime catalog for these two declarations only. Its legacy public
renderer is LP64; rescale its pointer-sized uint8/int8 slots to the selected DataOrganization.pointer.
The helper accepts ILP32/LP64, or Windows LLP64 for portable memcpy, with 4-byte int. Keep pointer returns
as void *; omit const/restrict as in the existing native catalog. Win32 x86 C memcpy uses explicit cdecl.
The musl source is provenance for declaration facts, not evidence that a target uses musl or Linux.
POSIX recv requires explicit target assertion, analyst assertion or a compatible posix-linux profile.
Neither ELF nor Platform::Default establishes POSIX/Linux. No off_t or socket structure layout is used.
